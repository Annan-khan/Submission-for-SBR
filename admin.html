Available sections

How it works

Choose a section from the dropdown, edit the values, then click Save. Use New to create a section or Delete to remove the selected section.

  • Refresh: reload section list from the database.
  • Select: choose a section to edit its key, name, and JSON data.
  • Save: updates an existing section or creates a new one.
  • Delete: removes the selected section from the database.
